## 2. Engine (port of `engine.py` + `symbols.py`)

Pitch-class based; no hand-entered fingerings anywhere. Port function-for-function and keep the fixtures as runnable tests (a `?test=1` query flag that logs pass/fail to the console is fine).

```
scale(parent)                       -> 7 pitch classes of the major scale
stack(scale, degree, steps)         -> pitch classes; steps: [3,3] q3, [3,3,3] q4, [3,3,2] sw4, [3,3,3,2] sw5
invert(voicing, k)                  -> rotate lowest k notes to the top (q3 only in v1)
place(voicing, stringSet, ceil=15)  -> fret tuples, span <= 4, both octave positions, ascending
intervalType(voicing)               -> 'P4/P4' | 'P4/TT' | 'TT/P4' | 'P4/M2' | ... (adjacent intervals)
label(bassPc, voicingPcs)           -> chord-symbol suffix or '—'   (spec §6.2, rules 1–6 in order)
spell(pc, parent)                   -> note name in the parent key's spelling
```

Families and string sets (settled):

| id | construction | string sets (low→high) | inversions |
|---|---|---|---|
| `q3` | 4th–4th | 5-4-3, 4-3-2 (default), 3-2-1 | 0, 1, 2 |
| `q4` | 4th–4th–4th | 5-4-3-2, 4-3-2-1 | 0 |
| `sw4` | 4th–4th–3rd | 4-3-2-1 | 0 |
| `sw5` | 4th–4th–4th–3rd | 5-4-3-2-1 | 0 |

Inversion names: **root position**, **1st inversion (4th–2nd)**, **2nd inversion (2nd–4th)** — workbook convention, never the handout's.

Modes = parent + offset (Ionian 0, Dorian 1, Phrygian 2, Lydian 3, Mixolydian 4, Aeolian 5, Locrian 6). Spelling always from the parent key.

Fixtures that must pass before any UI work:
- Appendix A of the spec (C major and B♭ major, every family/string set) — fret-for-fret.
- The 36 root-position symbols of Ex. 5/10/11 and the ~40 symbols listed in spec §7–8 — string-for-string, including the `—` cases.

## 3. App structure — six tabs

Tab pattern and card styling as in Arpeggios Deck. Persistent header controls: **Key** (12, flats spelling as in the workbook: D♭ G♭ A♭ B♭ E♭), **Family**, **String set**, **Inversion** (q3 only), **Show bass note** toggle (Function/Progressions/Tunes), **Play** (audio). Selections persist across tabs for the session (in memory only).

### 3.1 Shapes
- Cards ascending by lowest fret (same ordering rule as the arpeggio parallel walk), one per placement; octave duplicates shown as separate cards with an "8va" tag.
- Card: chord grid (Box Buddy engine), note names low→high, interval type badge. The two tritone voicings of the key get a distinct badge colour from the five P4/P4 ones; inversion cards show the derived interval type (P4/M2 etc.).
- "Neck" toggle: fretboard-walk view (Fretboard app component) with all placements of the current family/inversion on one neck, top notes emphasised.

### 3.2 Modes
- Mode + tonic pickers, plus presets: D Dorian, E♭ Dorian, G Mixolydian, F Mixolydian, F Lydian, E Phrygian.
- Same cards as Shapes; label under each card = top note's degree in the mode (1 ♭3 4 5 ♭7 … ), note name as second line.
- **Pentatonic filter** (spec §5.3): Off / Minor pentatonic / Blues. Pentatonic root: mode tonic for Dorian/Aeolian/Phrygian; 5th of tonic for Mixolydian; 6th of tonic for Ionian/Lydian; Locrian: tonic (♭5 already diatonic — no blue-note hint needed). Cards whose top note is in the scale stay full strength, others dim to ~35%. In Blues mode, show a hint strip: "♭5 of the pentatonic (note) isn't diatonic — approach it by planing a neighbouring voicing a half step," and outline the cards whose top notes sit a half step above and below it.
- Practice-directions panel: the four handout directions verbatim (spec §5.4).

### 3.3 Function
- One shape held fixed (current family/inversion/placement; a picker for placement). Twelve columns, bass descending chromatically from E (Ex. 5 order: E E♭ D D♭ C B B♭ A A♭ G G♭ F).
- Each column: bass note + string/fret (6th string, falling back to 5th when the 6th-string fret would exceed 15 or drop below 0 — the workbook uses both), chord symbol from `label()`, top note's degree relative to that bass. `—` columns render greyed with the tooltip "contains both 7ths / both 9ths — no usable symbol."
- Guidepost panel: for the selected family, auto-derived table "to sound like X, top note must be Y" per inversion (spec §6.3 is the P4/P4 case and is the acceptance test).
- Audio: click a column to hear shape + bass.

### 3.4 Progressions
- ii–V–I, all keys, cycle-of-4ths or fixed key.
- Presets Ex. 6a–6c, 8a–8h exactly as spec §7.1 (in C or D as written; transpose by nearest-position when the key changes). "Custom": choose (function-target, inversion) per chord — ii: m11; V: 7alt.; I: 6/9 or Δ13 or Δ7(♯11) — engine picks the shape whose top-note guidepost satisfies the target, nearest placement to the previous chord (reuse Voice-Leading Trainer's nearest-inversion search).
- **Planing** control: "plane V → I by half step" on/off, direction up/down; render the arrow and "(half-step planing)" text as the workbook does.
- Bass toggle; metronome (Two-and-Four scheduler, 2 beats per chord default, I gets 4).
- Display: staff + TAB (pre-rendered) with chord symbols, grids beneath.

### 3.5 Tunes
- "Solar" (12 bars) and "Stella by Starlight" (32 bars) exactly per spec §8.1–8.2 (bar 8 of Stella = A♭13). Chord symbols and voicings only — no melody, ever.
- Each bar: symbol, grid + TAB, bass note (per toggle), and a one-line reading ("E♭–A–D 2nd inversion: over F, A = 3, E♭ = ♭7, D = 13"). Reading text is generated from `label()` degrees, not hand-typed.
- Loop playback with the metronome; bar-by-bar reveal mode for practice.
- Store tunes as data: `{ bar, symbol, notes:[pcs low→high], strings:[...], frets:[...], bass:{string, fret} }`. Frets are the workbook's; do not re-place them.

### 3.6 Practice
Drills per spec §9, in this order: Linear walk · Name that voicing · Which note on top? · Harmonize the pentatonic · ii–V–I in all keys · Tune loop. Reuse existing drill components (Fretboard walk, Shell Voicing Builder's Name-That-Chord loop, Voice-Leading Trainer's progression loop). Scores are session-only.

## 4. Intro panel
Reading text from spec §2, serif, reachable from a "Read" button on every tab (as in Scale Practice). Keep your prose verbatim except the trims already made in the spec.

## 5. Chord-symbol typography
Workbook forms with the Shell Voicing Builder glyph set: `Δ` superscript, `ø`, `°`, `alt.` with the period, minor = `m`, `6/9` as a stacked fraction glyph if available else `6/9`. Flats/sharps as ♭/♯ glyphs. Examples that must render: `Dm11`, `G7alt.`, `C6/9`, `CΔ13`, `Eø11`, `A♭Δ7(♭9♭5)`, `B♭7(♭9♯11)`, `Cm(Δ11)`, `A♭°7(♭13)`, `G♭Δ7(♭5sus4)`.

## 6. Notation pipeline
- `gen-quartal.js`: emits LilyPond for (a) every Shapes/Modes card in staff+TAB per key — 12 keys × families × string sets × inversions ≈ 1,100 cells, same budget as arpeggios; (b) the Progressions presets in all 12 keys; (c) the two tunes. Pre-render per key as static files (the transposition-label approach showed the wrong key before — don't).
- Argue conventions on example pages: measure numbers under every bar, double bars between examples; chord symbols above.
- TAB digits: notehead anchors at its left edge (1.23 spaces), not centred — reuse the correction from the Fretboard work. Live fallback renderer (Feta glyph outlines) only if a cell is missing.

## 7. Audio
Web Audio, synthesized voices only; shape + optional bass; metronome via the shared lookahead scheduler (25 ms interval, 130 ms lookahead). Chord playback strums low→high with ~15 ms spacing.

## 8. Acceptance checklist

2. All Ex. 5/10/11 symbols and all §7–8 symbols reproduce; `—` where the spec has `—`.
3. Guidepost table for P4/P4 matches spec §6.3.
4. Ex. 8b and 8h render with the planing arrow; presets transpose to all keys without exceeding fret 15 (choose the octave placement that fits; if none, drop to the other octave and flag in console).

6. No browser storage APIs; single file; loads offline from the repo checkout.
