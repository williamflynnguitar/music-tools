# Music tools

Small, self-contained browser tools for jazz guitar practice and teaching, by
William Flynn. Each tool is a single HTML file with no dependencies, no build
step and no account — open it and play. Built for students on a phone in a
practice room.

**Live:** https://williamflynnguitar.github.io/music-tools/

- **two-and-four/** — a time trainer that clicks on beats 2 and 4, then fades
  out so your inner clock does the work
- **fretboard/** — movable scale fingerings, ten scales, every key
- **scales-deck/** — Scale Practice 101 as a step-through deck of cards
- **arpeggios-deck/** — arpeggio practice: parallel shapes, HDA and VDA

These tools are the companion to the **Jazz Guitar Technique Handbook, 3rd
edition**; the fingering and exercise data is derived from it. The book itself
is not included here.
